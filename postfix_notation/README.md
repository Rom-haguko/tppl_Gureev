# Стековая машина (Постфиксная нотация)

Решение задачи по дисциплине **"Теория и практика языков программирования"** (Группа 14323-ДБ ПИ).  
Программа вычисляет арифметические выражения, записанные в постфиксной (обратной польской) нотации.

## Поддерживаемые операции

- `+`, `-`, `*`, `/` — базовые арифметические операции.
- `~` — специальный оператор:
  - Если оба операнда не равны 0: вычисляет модуль разницы `|x - y|`.
  - Если хотя бы один операнд равен 0: суммирует весь стек (включая операнды), возводит сумму в квадрат и кладёт результат обратно в стек.

## Требования

- Python 3.10+
- `pytest`, `pytest-cov` (для тестов и измерения покрытия)

## Как запустить

### Вариант 1: С использованием Makefile (рекомендуется)

1. Установите зависимости:
    ```bash
    make install
    ```

2. Запустите программу, передав выражение через переменную `EXPR`:
    ```bash
    make run EXPR="3 0 4 ~ 2 ~"
    ```

### Вариант 2: Прямой запуск через Python

    ```bash
    python main.py "3 0 4 ~ 2 ~"
    ```

## Тестирование и покрытие

Проект полностью покрыт модульными и интеграционными тестами.

### Запуск тестов

    ```bash
    make test
    ```

### Проверка покрытия (Coverage)

Для проверки процента покрытия кода тестами выполните:

    ```bash
    make coverage
    ```

Команда выведет таблицу покрытия в консоль, а также сгенерирует подробный HTML-отчёт в папке `htmlcov/`. Откройте `htmlcov/index.html` в браузере, чтобы увидеть детализацию по строкам.

## Очистка проекта

Чтобы удалить временные файлы, кэш и отчёты о покрытии:

    ```bash
    make clean
    ```
