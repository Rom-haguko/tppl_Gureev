# Выбор парадигмы и языка программирования

## Задача 1. Обработка больших данных в реальном времени
* **Парадигма:** Императивная и объектно-ориентированная.
* **Язык программирования:** C++
* **Обоснование:** 
  * Императивный подход позволяет явно указывать порядок действий и работать с конкретными участками памяти.
  * Язык C++ обладает высокой скоростью выполнения.
  * Отсутствие автоматического сборщика мусора гарантирует отсутствие задержек, что критично для работы в режиме 24/7 без остановок.
  * Прямое управление памятью позволяет эффективно обрабатывать огромный поток данных (~3.3 ГБ/с) и использовать низкоуровневые оптимизации (например, GPU-ускорение) для математических вычислений.

## Задача 2. Прототип ML-сервиса для прогноза погодных условий
* **Парадигма:** Императивная / Скриптовая.
* **Язык программирования:** Python
* **Обоснование:**
  * Python является стандартом и оптимальным выбором для создания прототипов ML-решений.
  * Язык обладает высокой легкостью создания программ, что позволит запустить MVP в жесткие сроки (за 2 недели).
  * Скриптовые языки обладают гибкой динамической типизацией и экономичностью выражений, что делает итерации и смену алгоритмов максимально быстрыми.
  * В экосистеме Python существует огромный набор готовых ML-библиотек (например, scikit-learn, TensorFlow, PyTorch).

## Задача 3. Интерактивный UI для торгового терминала
* **Парадигма:** Реактивная и декларативная.
* **Язык программирования:** TypeScript (с использованием фреймворков React/Vue)
* **Обоснование:**
  * Реактивное программирование описывает то, как система должна реагировать на изменения, что идеально подходит для потоков данных из WebSocket и сложных взаимодействий между виджетами.
  * Декларативный подход и реактивность являются современным стандартом для разработки фронтенда.
  * Внедрение статической типизации (TypeScript) значительно повышает надежность кода и делает тестирование 50+ виджетов намного проще.
  * Виртуальный DOM в современных фреймворках обеспечит мгновенную отрисовку (< 16 мс).

## Задача 4. Прошивка для устройства регистрации температуры
* **Парадигма:** Императивная.
* **Язык программирования:** C
* **Обоснование:**
  * Язык C (и C++) является основным инструментом для разработки под встраиваемые системы.
  * Императивный подход обеспечивает прямой доступ к регистрам, портам ввода-вывода (GPIO, ADC, UART) и аппаратному обеспечению.
  * Язык обеспечивает низкое потребление памяти, что является жестким требованием при наличии всего 32KB RAM.
  * Отсутствие тяжелого рантайма гарантирует детерминированное время отклика (real-time) и минимальное энергопотребление батареи. Компиляторы языка C существуют для большинства микроконтроллеров, что решает проблему переносимости.
